colorburst

An operating system built around the browser: simple, and hard to break.

Join the Discord — questions welcome.

What it is

An operating system that works out of the box and keeps working. It bets that most of what you do now happens in a browser, and takes back something in return: there is very little left to go wrong.

That makes it a good thing to install on someone else's computer. Nobody calls you at 11pm because it broke.

  • The account is created on the machine. No Google account, no network needed to sign in.
  • No Google services. Nothing is sent anywhere to log in or to use the machine.
  • Runs on desktops and laptops that Windows 11 will not take.
  • Updates arrive on their own, from colorburst's own update server.

Who installs it

  • A relative whose computer is only ever a browser, and who would rather not think about it again.
  • An old machine that is not worth a Windows licence, or that Windows refuses to install on.
  • Anyone who wants a laptop that does not need an account with anybody.

Try it from a USB stick — it runs without touching the disk.

Where the project is

Early, and honest about it. It installs, updates and runs; parts of the interface still say "Chromium", DRM video does not play, and there is no password recovery. The FAQ is specific about what is missing.
