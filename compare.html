Where colorburst loses

  • Windows software does not run. No Office desktop, no Photoshop, no games. Web versions work; installed Windows programs do not.
  • DRM video does not play. Netflix and similar are out.
  • No hardware video decode yet, so heavy video costs more battery than it should.
  • Specialised hardware is unlikely to work — scanners, older printers, anything with a Windows-only driver.
  • No password recovery. The account is only on your machine, so there is no server to reset it.

Where it wins

  • It stays fast on hardware Windows has given up on.
  • It resets to a clean state in minutes, not an afternoon.
  • It needs no account with anyone, and sends nothing anywhere to sign in.
  • It updates itself without interrupting you.

Compared with ChromeOS Flex

Flex is Google's own way of putting ChromeOS on an old PC, and it is good at it. The difference is the account: Flex requires a Google sign-in and is tied to Google's services. colorburst creates the account on the machine and talks to no one. If you want Google's ecosystem, use Flex — it is better supported.
